# Hang_Man_Web_based_Game
Interactive full-stack Hangman game with animated visuals, database integration, difficulty levels, statistics, sound effects, and responsive design.

# 🎮 Animated Hangman Game
An interactive and responsive **full-stack Hangman game** featuring animated gameplay, multiple difficulty levels, database-backed word management, game statistics, sound effects, and light/dark themes.

# ✨ Features
 🎯 Interactive Hangman gameplay
 🎨 Animated Hangman figure with smooth animations
 🔤 Interactive A–Z keyboard
 ⌨️ Physical keyboard support
 💡 "Reveal a Letter" hint system
 🏆 Win and loss detection
 🔄 Play Again functionality
 📊 Games played, wins, losses, win rate, and streak statistics
 📚 Multiple word categories:
   Animals
   Countries
   Food
   Movies
   Technology
🎚️ Easy, Medium, and Hard difficulty levels
  🔊 Sound effects with mute option
 🌙 Light and Dark theme
 📱 Responsive design for desktop and mobile
 🗄️ Database-backed word bank and game results
 📜 Recent game history

#🗄️ Full-Stack Functionality
The application uses a database to store the game's word bank and game results. Each completed game can be recorded with information such as the result, word, category, wrong guesses, and date.

The database-backed statistics allow players to view their overall performance, current streak, best streak, and recent game history.

#🎮 How to Play
1. Select a difficulty level.
2. A random word is selected from the database.
3. Guess letters using the on-screen keyboard or your physical keyboard.
4. Correct guesses reveal letters in the word.
5. Incorrect guesses progressively build the Hangman figure.
6. Use the hint button when needed.
7. Guess the complete word before running out of lives.
8. Start a new round and try to improve your statistics.
